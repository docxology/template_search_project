# Manuscript

Single source for paper text and [`config.yaml`](config.yaml) (search query, sources, enrichment, LLM). The pipeline fills [`references.bib`](references.bib) from the standard query.
The retained [literature supplement](S01_literature_review.md) cites
[`references_deep.bib`](references_deep.bib). The combined edition renders
entries from both files.

[Open the current HTML reader](../reader/README.md) or browse the
[original published snapshot](../../output/web/index.html).
