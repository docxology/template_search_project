# References {#sec:references}

The standard analysis writes `docs/manuscript/references.bib` from the
single-query results. The archived deep-search run supplies
`docs/manuscript/references_deep.bib` and the citations in
[@sec:supplemental_s1]. The pinned renderer uses both bibliographies to
resolve citations.

Run the offline workflow documented under `docs/quickstart.md` to
regenerate the standard bibliography. A new deep-search run requires an
explicit source configuration. The composer then builds a supplemental
section from its outputs.
