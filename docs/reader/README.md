# Current HTML reader

Open [web/index.html](web/index.html) in a browser from a local checkout. The
combined reader includes the offline single-query fixture and the retained
deep-search literature supplement. Standard search references come from
[references.bib](../manuscript/references.bib). The supplement cites the
separate [references_deep.bib](../manuscript/references_deep.bib).

The [original HTML snapshot](../../output/web/index.html) remains in the
published output tree. For a current PDF or to refresh this reader, use the
[pinned offline build and reader checks](../rendering_pipeline.md#refresh-the-current-html-reader).
